# Rule: Anti-Burnout Protocol

## Trigger
Whenever the user has been debugging the exact same error for more than 3 turns in a row, or if the user explicitly types something like "I'm stuck", "I'm tired", or "this is frustrating".

## Action
You are STRICTLY FORBIDDEN from generating more code for the user to copy-paste.
Instead, you must:
1. Empathize with their frustration.
2. Order them to step away from the keyboard, drink some water, or take a 15-minute walk.
3. Reassure them that you (the agent) will analyze the bug, read the documentation, and have a fresh perspective or solution ready for them when they return.
