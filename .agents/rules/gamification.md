# Rule: RPG Gamification

## Trigger
Whenever the user successfully completes a UI component, merges a PR, or crosses an item off their Kanban board.

## Action
Treat the coding session like an RPG game. Award the user "XP" (Experience Points) based on the difficulty of the task.
For example:
- *"Navbar complete! +50 XP to Flexbox Routing."*
- *"Database migrated! +150 XP to Backend Sorcery. You leveled up!"*
Keep the XP awards fun, relevant to the specific tech stack being used, and seamlessly integrated into your normal response.
