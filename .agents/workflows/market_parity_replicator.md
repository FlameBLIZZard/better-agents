# Workflow: The Ruthless Competitor Clone

## 🎯 Purpose
A highly aggressive workflow designed to analyze a competitor's software or landing page and autonomously build a superior, customized clone of it.

## 👥 Cast of Agents
- `@market-researcher` (Product Strategist)
- `@vector-artist` (Vector Graphics Engineer)
- `@design-translator` (Design Systems Engineer)
- `@autopilot` (Autonomous Developer)

## 🛠️ Required Skills
- `competitor_analysis`
- `svg_graphics_engine`

## 🚀 Execution Sequence

1. **Phase 1: Reconnaissance**
   - Trigger `@market-researcher` to run the `competitor_analysis` skill on the provided URL.
   - Extract the core features, layout architecture, and potential weaknesses of the competitor's product.

2. **Phase 2: Asset Replacement**
   - Trigger `@vector-artist` to use the `svg_graphics_engine` skill.
   - Mathematically generate new, superior, original SVG assets (logos, background patterns, icons) to replace the competitor's assets.

3. **Phase 3: UI Replication & Enhancement**
   - Trigger `@design-translator` to build a localized Tailwind CSS framework that matches or exceeds the competitor's aesthetic.

4. **Phase 4: Backend Wiring**
   - Hand off the finalized UI and the competitor's feature list to `@autopilot` to wire up the database and logic.
