# Workflow: The Legacy Modernizer

## 🎯 Purpose
Orchestrates the surgical refactoring of ancient, legacy codebases (e.g., old jQuery/PHP or monolithic React) into modern, decoupled architectures like Next.js App Router or Clean Architecture.

## 👥 Cast of Agents
- `@system-architect` (Infrastructure Lead)
- `@design-translator` (Design Systems Engineer)
- `@silent-fixer` (Automated Debugger)

## 🛠️ Required Skills
- `architecture_scaffolding`
- `auto_linter_loop`

## 🚀 Execution Sequence

1. **Phase 1: Structural Analysis**
   - Trigger `@system-architect` to read the legacy codebase.
   - Use the `architecture_scaffolding` skill to propose a strict, modernized Domain-Driven blueprint that maps the old files to their new locations.

2. **Phase 2: UI Translation**
   - Trigger `@design-translator` to ingest legacy CSS/SCSS files and convert them into strict, modernized Tailwind CSS utility classes.

3. **Phase 3: Logic Migration**
   - Trigger `@silent-fixer` to migrate the business logic piece-by-piece to the new architecture.
   - Run the `auto_linter_loop` continuously in the background to catch syntax errors during the migration.
